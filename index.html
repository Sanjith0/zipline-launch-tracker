How the numbers are computed

Reporting date
Every stage and metric is evaluated as of this date. Dates after it are ignored, so moving it back replays the pipeline as it looked then. The dataset's last recorded event is 2027‑05‑30; the default is the day after.
Stage
The latest milestone dated on or before the reporting date.
% on target
Merchants that met the target ÷ merchants whose outcome is known. A merchant still open but already past the deadline counts as a miss; one still inside the window is excluded as pending. Counting only completed merchants overstates performance, so that figure is shown as a secondary note.
Days
Calendar days, as the targets are defined.
Setup data
Readiness requires menu setup and a drone loading location. A missing menu ID or drone loading ID is flagged as a blocker.
Weeks
Monday‑start weeks, labelled by their first day.
